# Training

The training script is self-contained PyTorch: it defines the model, the
dataset and the training loop, and does not require the
[pytorch-CycleGAN-and-pix2pix](https://github.com/junyanz/pytorch-CycleGAN-and-pix2pix)
framework to run. The pix2pix objective (L1 plus adversarial loss) and the
U-Net generator are reimplemented here, adapted for sun vector conditioning.

| File | Purpose |
|---|---|
| `train_custom_solar.py` | model definition (`SunConditionEncoder`, `FiLMIN`, `SolarGenerator`, `ConditionalDiscriminator`), dataset and training loop |
| `validate_model.py` | inference validation against held-out samples; imports `SolarGenerator` from `backend/app/models/networks.py` |

## Data layout

The dataset is generated by the Grasshopper definition in `gh_scripts/` and is
not tracked in this repository. The training script expects:

```
datasets/direct_sun_hours/
├── train_data_log.jsonl    # sun vectors and file references per sample
└── ...                     # paired height map and solar exposure images
```

`scripts/rename_dataset.py` renumbers image files when a new batch is appended.

## Run

```bash
pip install torch torchvision opencv-python numpy
python training/train_custom_solar.py
```

Paths, batch size, learning rate and epoch count are set at the top of
`train_custom_solar.py`. Training details and the validation procedure are
documented in [../docs/development.md](../docs/development.md).
